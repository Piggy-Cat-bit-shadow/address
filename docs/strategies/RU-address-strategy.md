# RU 俄罗斯地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik OpenStreetMap `russia` |
| 格式 / 邮编 | `<postcode>, <region>, <locality>, <street>, <house>`； корпус/квартира 缺失不补；源记录；格式门禁 6 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | Rosstat/行政区目录作为候选核验；当前源字段与 catalog 反查，含坐标锚定与 Cyrillic 清洗。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 明确住宅建筑标签；行政区文本与坐标冲突时丢弃。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 俄语行政层级不能从街道名猜测；跨境和脚本异常记录直接拒绝。 暂不采用：FIAS/ФИАС 与 Rosreestr 服务存在访问/许可差异，未作为默认依赖。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
