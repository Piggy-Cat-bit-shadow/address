# TR 土耳其地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik `turkey` |
| 格式 / 邮编 | `<street> <no>, <district>/<province> <postcode>, TR`；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；TurkStat 行政目录作为候选核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 住宅建筑标签；无住宅证据隔离。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 土耳其门牌后缀/公寓号仅保留源字段。 暂不采用：官方地址服务未完成本地验证，不接入。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
