# MX 墨西哥地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<street> <house>, <colonia>, <municipio>, <estado>, <CP>, MX`；缺失字段留空；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | INEGI Marco Geoestadístico/municipios 作为候选交叉核验；当前使用源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | 住宅建筑标签或明确住宅用途证据；商业/政府/学校等黑名单剔除。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | `colonia` 不能由城市或邮编反推；坐标与行政层级必须一致。 暂不采用：INEGI 地址/街道产品需逐项核实再分发，未作为当前主源。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

- 默认 active 地址目标 30,000；州、市镇、地区单节点上限 2,000/300/70，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
