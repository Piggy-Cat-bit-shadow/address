# CA 加拿大地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<house> <street>, <city>, <province> <A1A 1A1>, CA`；不添加虚构单元号；源记录；格式门禁 `A1A 1A1`（允许无空格），不生成邮编。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | Statistics Canada Census Subdivision/Boundary Files 作为候选交叉核验；当前以同步源与 catalog 反查为准。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | 明确住宅建筑标签或建筑用途证据；证据缺失则不发布为住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 加拿大邮编不是连续数值空间，不能用邻近邮编补齐。 暂不采用：Statistics Canada National Address Register 可评估，但重新分发许可和完整性须单独核实，当前未接入。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
