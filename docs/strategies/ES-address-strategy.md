# ES 西班牙地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<street> <house>, <postcode> <municipality>, <province>, ES`；楼梯/门号仅保留真实字段；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | INE/IGN 行政边界作为候选核验；当前源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | 建筑住宅标签或明确用途证据。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 邮编前两位可作省级一致性检查，但不能反推完整地址。 暂不采用：Catastro/INE 物业数据涉及许可和个人数据边界，未接入。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
