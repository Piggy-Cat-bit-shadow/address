# AU 澳大利亚地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（可能含 G-NAF 来源标识） |
| 格式 / 邮编 | `<unit> <house> <street>, <suburb> <state> <postcode>, AU`；unit 缺失不补；源记录；格式门禁 4 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | ABS ASGS 作为候选核验；当前源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | 明确住宅建筑/用途证据；G-NAF 地址存在不等于住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 州缩写、suburb 和邮编必须来自同一源记录或一致的目录反查。 暂不采用：G-NAF 许可与再分发条款需逐版本核验；当前随 Overture 来源记录处理。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

- 默认 active 地址目标 35,000；州/领地、城市、区县单节点上限 4,000/350/80，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
