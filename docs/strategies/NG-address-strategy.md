# NG 尼日利亚地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik `nigeria` |
| 格式 / 邮编 | `<house> <street>, <district>, <city>, <state> <postcode>, NG`；缺失字段留空；仅保留源记录且通过 6 位格式门禁；缺失合法，不推算。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；Nigerian administrative boundary 数据作为候选核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 住宅建筑标签；地址点稀疏时不扩散到附近建筑。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 低覆盖国家宁可返回无覆盖，也不使用随机或邻近地址。 暂不采用：全国统一开放地址注册库未完成可访问性/许可验证，暂不接入。 |
| 策略版本 / 状态 / 更新 | 1.1 / 严格质量门禁 / 2026-07-28 |

- 默认 active 地址目标 10,000；州、地方政府区、地区单节点上限 1,000/200/50，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
