# US 美国地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<house> <street>, <city>, <state> <ZIP>, US`；地址行使用源记录，不拼接虚构 Apt/Unit；源记录 ZIP/ZIP+4；仅接受 `\d{5}` 或 `\d{5}-\d{4}`，不自行推算 ZIP。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | Census TIGER/Line 与 Census Gazetteer 作为交叉核验候选；当前入库行政层级来自同步源字段与本地 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM `building=house/apartments/...` 或 Overture buildings 明确住宅类别；没有证据只进隔离区，不进入住宅发布池。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 当前源探测到 Overture STAC；住宅覆盖必须以本地样本门禁结果为准，不能因有 ZIP 就判定住宅。 暂不采用：US National Address Database/TIGER 需逐州许可与覆盖核验，未作为可再分发主源。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
