# IT 意大利地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<street>, <house> - <CAP> <locality> (<province>), IT`；内部号缺失不补；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | ISTAT comuni/province 作为候选核验；当前源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | 住宅建筑标签或用途证据；CAP 只证明邮区。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 城市/省缩写必须来自源或目录，禁止猜测。2026-07-29 本地验证 ISTAT 官方市镇 CSV HTTP 200，可用于行政区核验，但不含门牌和住宅用途；当前 Overture 快照在严格门禁下为 0，不发布。 |
| 策略版本 / 状态 / 更新 | 1.2 / 等待完整门牌与住宅用途证据 / 2026-07-29 |

- 默认 active 地址目标 35,000；大区、市镇、区单节点上限 2,500/350/80，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。
- 同一源版本产生 0 条合格记录时标记 `SOURCE_QUALITY_FAILED`，只重查源版本元数据；上游版本或适配/清洗版本变化后自动重试。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
