# SG 新加坡地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik `malaysia-singapore-brunei` 的 SGP 边界分片 |
| 格式 / 邮编 | `<BLK_NO> <ROAD_NAME>, <BUILDING>, Singapore <POSTAL>`；门牌、道路或邮编缺失即淘汰；源记录/OneMap；格式门禁 6 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；OneMap 可选地址核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM/建筑住宅标签；OneMap Search 仅证明地址存在，不单独赋予住宅证据。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 质量高于数量。仅发布 E3：地址存在与独立住宅用途证据同时成立；本国格式规定的必填组件缺一即淘汰，字段冲突拒绝合并；只允许可逆、可验证的格式规范化。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 2026-07-28 本地用三个脱敏邮编探测：HTTP 200，返回 `BLK_NO/ROAD_NAME/BUILDING/POSTAL/LATITUDE/LONGITUDE`，邮编与查询一致；Token 绝不写入文档或 Git。 暂不采用：将 OneMap 作为住宅用途证据或无限额度批量主源；Token 仅本地加密配置，按保守预算、HTTP 429/配额响应和到期状态自动暂停。 |
| 策略版本 / 状态 / 更新 | 1.1 / 严格质量门禁 / 2026-07-28 |

- 默认 active 地址目标 8,000；规划区层级单节点上限 8,000/500/80，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
