# KR 韩国地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik OpenStreetMap `south-korea` |
| 格式 / 邮编 | `<postcode> <시/도> <시/군/구> <도로명> <건물번호>`, apartment/dong/ho 缺失不补；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 仅使用 OSM 源字段与本地 catalog 反查；Juso/data.go.kr 当前不接入。层级与坐标冲突时拒绝发布。 |
| 住宅证据 | OSM 明确住宅建筑标签；道路名地址存在不等于住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 不保存或猜测栋/单元/室号；来源字段不完整时隔离。 暂不采用：Juso 与 data.go.kr 申请流程需要手机号/账户资料，本环境无法完成申请，未使用；旧 GitHub 邮编仓库数据过期，排除。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
