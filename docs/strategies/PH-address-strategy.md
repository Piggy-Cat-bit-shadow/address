# PH 菲律宾地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik `philippines` |
| 格式 / 邮编 | `<house> <street>, <barangay>, <city/municipality>, <province> <postcode>, PH`；源记录；格式门禁 4 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；PSA PSGC 作为候选核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 住宅建筑标签；barangay 名称不能证明住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 城市/省级字段缺失时不靠邮编反推行政区。 暂不采用：官方地址注册数据未完成许可与覆盖验证，暂不接入。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

- 默认 active 地址目标 15,000；大区、省、市县、Barangay 单节点上限 2,500/500/150/40，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
