# MY 马来西亚地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik `malaysia-singapore-brunei` 的 MYS 边界分片 |
| 格式 / 邮编 | `<unit/lot>, <building>, <street>, <postcode> <town>, <state>, MY`；缺失 unit 不补；源记录；格式门禁 5 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 源字段与 catalog；DOSM 行政目录作为候选核验。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 明确住宅建筑标签；商业 POI 黑名单剔除。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每日检查上游分片；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 同一 PBF 下载按 MYS/SGP 边界分片，避免国家串行污染。 暂不采用：官方地址服务需逐项验证许可，当前不依赖第三方 API。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
