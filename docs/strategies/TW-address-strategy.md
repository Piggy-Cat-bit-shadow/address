# TW 中国台湾地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<postcode> <county/city><district><road> <section><lane><alley> <number> <floor>`, 缺失字段不补；源记录；格式门禁 3–6 位数字，保持来源位数。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | 仅使用 Overture 源字段与本地 catalog 反查；TGOS/MOI 在线服务当前不接入。层级与坐标冲突时拒绝发布。 |
| 住宅证据 | 住宅建筑标签或明确用途证据；邮编和行政区不构成住宅证据。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | 台湾记录执行 locality 软修复与坐标/行政一致性检查；无法确认的记录不发布。 暂不采用：TGOS 本地探测不可用，放弃作为依赖；旧 southkorea 等仓库与台湾无关，不使用。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

- 默认 active 地址目标 25,000；县市、区乡镇、村里单节点上限 2,000/300/70，后台可覆盖；只裁剪地址记录，行政区划与邮编目录保持完整。

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
