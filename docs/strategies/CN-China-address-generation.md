# CN 中国地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | AreaCity/StatsGov 行政区版本 + 高德、百度、腾讯住宅小区 POI；不再使用旧 OSM 中国住宅池作为中国发布源。 |
| 格式 / 邮编 | `省 市 区县 街道/道路 小区` ；只输出来源字段；6 位邮编仅在精确来源存在时保留。 |
| 行政区 | AreaCity 主源，民政部版本页对照；省/市/区县/街道层级和法定后缀必须一致。 |
| 住宅证据 | 高德候选必须是 `typecode=120302` 且 `adcode` 与目标区县一致；同一小区至少两个独立地图平台的名称、行政区、地址与坐标一致；单平台记录不发布。 |
| 发布门禁 | 仅发布 L2/L3；非空门牌冲突拒绝合并；小区与两个来源证据均须在 180 天有效窗口内；缺失字段保持空。 |
| 同步频率 | AreaCity 发布新版时更新行政区；POI 按免费额度分页补齐；新快照通过门禁后原子切换。 |
| 验证 / 排除 | 保留 GCJ-02/BD-09 原坐标，WGS-84 只用于索引；排除旧 OSM 小区词库、随机小区、随机门牌与随机栋室。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

## 查询与额度

- 高德按 AreaCity 的 6 位区县 `adcode` 查询，固定 `types=120302`、`city_limit=true`，最多读取 8 页（官方单查询最多 200 条）。
- 每个 WebService Key 默认是独立额度；高德关键字搜索按个人认证基线 `5,000/月、3 QPS` 使用到本月耗尽，百度和腾讯按各自日周期累计。
- 腾讯返回 `X-Limit` 时显示平台实时已用量与上限；高德、百度响应不提供剩余额度时显示本地统计，并由平台超限错误校正状态。
- 后台显示当前周期已用、上限、剩余、统计来源和重置时间；额度耗尽后暂停该 Key，到周期边界自动恢复。
- 默认 active 地址目标 40,000；省级/地级市/区县/街道乡镇单节点上限为 2,500/400/30/10，可在后台覆盖。配额只约束地址，不裁剪 AreaCity 行政区或邮编目录。

## 凭据边界

- `AMAP_API_KEY`：仅服务端 WebService 同步，可在后台添加多个并按免费预算轮换。
- `AMAP_JS_API_KEY`：独立浏览器 Key；公开站点启用高德时会在网络请求中可见，必须设置正式域名白名单，不与同步 Key 复用。
- `AMAP_JS_SECURITY_CODE`：仅在服务器以 AES-GCM 密文保存，只由 `/_AMapService` 代理使用。
- Security Code、同步 Key 和其他 Token 不进入前端、Git 或日志；示例值全部是空值或占位符；VPS 运行配置权限为 `600`。

统一证据等级、配额、自动同步与来源验证见 [数据源与自动同步方案](../data-sources.md)；运行参考见 [CN DOCX](CN-China-address-generation-and-key-rotation.docx)。
