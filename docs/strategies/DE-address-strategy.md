# DE 德国地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses（当前批量主源） |
| 格式 / 邮编 | `<street> <house>, <postcode> <locality>, DE`；Wohnung/Etage 缺失保持空；OpenPLZ/源记录；格式门禁 5 位数字；不得用几何最近邮编补齐。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | Destatis GV100AD 作为候选核验；OpenPLZ 街道目录仅辅助，不覆盖门牌。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅证据 | OSM 明确住宅建筑标签；街道目录或邮编多边形不构成住宅证据。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 发布门禁 | 仅发布 E3：地址存在与独立住宅用途证据同时成立；字段冲突拒绝合并，缺失字段保持空。 |
| 同步频率 | 每月检查上游版本；新快照通过门禁后原子切换，失败保留上一 active 快照。 |
| 验证 / 排除 | OpenPLZ README 明确几何匹配并非 100%，所有冲突记录必须拒绝发布。 暂不采用：OpenPLZ 数据仓库 README 可访问，但其 API 路由探测返回 404，故不作为运行时依赖；Deutsche Post 完整邮编产品未接入。 |
| 策略版本 / 状态 / 更新 | 1.0 / 当前主链路 / 2026-07-28 |

统一证据等级、许可、配额与 VPS 边界见 [数据源与自动同步方案](../data-sources.md)。策略变化时同步更新本文件、实现与测试。
