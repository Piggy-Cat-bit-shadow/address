# 各国地址格式与邮编规则

更新：2026-07-28。格式化只重排、规范化来源字段，不生成缺失的门牌、建筑、公寓、单元、楼层、房间或邮编。

## 通用规则

- 原文地址是主表示；英文和简体中文是同一组真实组件的转写/翻译。
- 邮编只接受来源值或精确权威关联值；格式错误或缺失时保持为空，不用附近邮编替代。
- 行政区必须与来源坐标和本地 catalog 一致；冲突记录隔离。
- 室内字段只有 `official` 或 `source_tagged` 来源才显示；人物、工作、财务、网络和沙盒银行卡属于合成测试资料。
