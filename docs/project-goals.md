# 项目目标

一句话：自托管的 27 国真实住宅地址生成器——地址存在与住宅用途双证据、地址字段全来源化、三语输出、严格筛选。

## 1. 产品目标

1. **准确性优先**：所有公开结果必须通过 E3 门禁；覆盖率、响应成功率和同步速度均服从地址准确性。
2. **双证据发布**：每条记录同时保存地址存在证据与同一地址或精确建筑关系的独立住宅用途证据。
3. **地址字段全真实**：门牌、小区、建筑、楼栋、单元、楼层、房间、邮编和坐标只保留来源值；缺失时保持为空。
4. **严格匹配**：州省、城市、区县、邮编等筛选按精确结果发布；目标地区无合格记录时返回无覆盖，不替换成附近、同州省或全国地址。IP 模式只接受坐标或城市匹配。
5. **跨源验证**：行政层级、邮编、坐标和国家边界必须一致；中国小区还要求至少两个独立地图平台一致。
6. **资料明确分层**：地址字段保留来源与证据；姓名、生日、电话、邮箱、职业、薪资、网络资料和沙盒银行卡属于独立的合成测试资料。

## 2. 技术目标

| 维度 | 目标 |
|---|---|
| 架构 | 单服务器自托管（`/root/address`），运行时查询 active SQLite 快照 |
| 存储 | SQLite WAL + RTree；数据目录软限 40 GiB、硬停 45 GiB、绝对上限 50 GiB |
| 性能 | 池内生成 p95 <100 ms；随机策略只选择合格记录，不生成地址字段 |
| 初始化 | 27 国按证据门禁连续初始化，支持断点续跑、失败隔离和重启恢复 |
| 同步 | 版本发现、规范化、交叉验证、事务导入、原子切换和回滚 |
| 配额 | 外部平台只使用配置的免费预算；达到 QPS、日/月额度或 Token 到期状态后暂停 |
| 隐私 | IP 不落库；生产数据、API 原始响应和凭据只保存在服务器私有目录 |
| 地图安全 | 同步 WebService Key 与浏览器 JS Key 分离；高德安全密钥仅由加密服务端代理使用 |

## 3. 明确边界

- 项目不构建全球全量地址镜像；每个国家按质量、许可和容量选择可发布子集。
- 公共生成链路只发布 E3 住宅记录；仅有地址存在证据的记录保留在候选层。
- 地址链路不合成门牌、小区、楼栋、单元、楼层、房间或邮编。
- 地区筛选和 IP 匹配不使用跨城市、跨州省或全国替换。
- `verified` 表示证据与质量门禁通过，不代表当前有人居住、可投递或对应特定住户。
- 服务器操作范围固定在 `/root/address`；生产数据库、密钥和原始响应不进入 Git。

## 4. 验收清单

- [ ] 每个对外开放的国家均存在 active E3 住宅快照；未覆盖国家或地区返回明确的无覆盖错误。
- [ ] 任一返回地址同时包含地址存在证据、住宅用途证据、来源记录 ID、版本、观测时间和坐标。
- [ ] 州省、城市、区县或邮编筛选只返回精确匹配记录；IP 模式只返回坐标或城市匹配记录。
- [ ] 中国记录来自 AreaCity 行政区与至少两个地图平台一致的小区、登记地址和坐标，室内缺失字段保持为空。
- [ ] 其他国家的地址对象与同一住宅建筑或明确住宅用途证据关联，邮编和行政区冲突记录不发布。
- [ ] 三语地址组件对应一致，数字、邮编、来源证据和坐标不因翻译改变。
- [ ] 地图链接只使用来源地址或来源坐标，不附加任何合成地址字段。
- [ ] Google/高德中国与国外开关相互独立；高德 JS 安全密钥不出现在浏览器响应、构建产物、日志或 Git 中。
- [ ] `npm test`、`npm run check`、`npm run build` 和生产就绪检查通过。
- [ ] 数据目录保持在容量门禁内，生产数据与凭据不进入仓库。
